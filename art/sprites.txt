; Sprite art for Meh-ga Man. tools/art2c.py turns this into build/gen/art_data.{c,h}.
;
; Every frame is 16 rows of: <color letter> <16 pixels>. '#' is a lit pixel, '.' is
; empty; a color letter picks a palette entry, and a '.' color marks a blank row.
; Each row has ONE color (the kernel streams a color per scanline for the sprite
; pair), so detail comes from stacking rows, not from colors within a row.
; All frames face right in side view; the renderer mirrors them for left.
; Characters are 8 pixels wide (the left half of the 16-pixel frame, so one
; player sprite): an Atari pixel is about 1.6 times wider than tall, so 8 wide
; by 16 tall has about the proportions of a 16x24 sprite on a console with
; squarer pixels. The right 8 pixels stay empty.
;
; The play sky is dark indigo and platforms are gold, so the hero's blues (with a
; cyan visor) stand out, and enemies use greens and reds.
